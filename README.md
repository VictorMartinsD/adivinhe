# 🧩 Adivinhe — Jogo de Adivinhação de Palavras

> ⚠️ **Status do Projeto:** 🚧 Em desenvolvimento

Uma aplicação web interativa desenvolvida em **React** que desafia o usuário a adivinhar palavras secretas a partir de dicas contextuais. O projeto conta com validação em tempo real de palpites, controle de tentativas restantes e exibição das letras já utilizadas.

---

## 📌 Sobre o Projeto

O **Adivinhe** é um jogo web onde o jogador precisa descobrir a palavra oculta informando uma letra por vez. A interface fornece orientações dinâmicas, limitando o número de tentativas e destacando o histórico de jogadas para auxiliar na tomada de decisão.

## 📂 Como Executar o Projeto

# Clonar o repositório

```bash
git clone [https://github.com/seu-usuario/adivinhe.git](https://github.com/seu-usuario/adivinhe.git)
```

# Entrar no diretório

```bash
cd adivinhe
```

# Instalar as dependências

```bash
npm install
```

# Iniciar o servidor de desenvolvimento

```bash
npm run dev
```
